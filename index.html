Матрица освоения

Освоен Частично освоен Не освоен Нет результата

Столбцы сгруппированы по элементам содержания и датам проверки. Прокрутите матрицу вправо, чтобы увидеть все элементы. Δ показывает изменение по одному элементу к предыдущей выбранной работе, где он проверялся. * — требуется проверка. Прочерк означает, что для сравнения нет двух результатов. Нажмите на ФИО для просмотра динамики.

Пороги и обозначения

Пороги задаёт учитель для сводных карточек и диаграмм. В матрице «освоен» означает полный балл по всем заданиям элемента; частичное выполнение отмечено отдельно. «Н» — не участвовал; «Уточнить» — неоднозначность исходных данных; «Не все задания оценены» — часть результатов не внесена; «Не проверялся» — элемент отсутствует в КОМ. Эти записи не считаются нулём.

Контрольно-оценочные мероприятия

Справочник элементов

По документу «6_klass_KOM_matematika.docx». У каждого задания — один основной элемент содержания и конкретное проверяемое умение.

Показать все элементы

Пример: «Дорожная карта 6БГИ», КР от 06.10.2026. Задания 3, 4, 5 и 7 сопоставлены с 1.1.5 (НОД и НОК). Для задания 7 дополнительная связь — 1.1.4 (текстовые задачи). У «взаимно простых» нет отдельного пункта: связь с 1.1.5 установлена по содержанию через НОД. Названия элементов приведены по кодификатору. Проверяемые умения сформулированы единообразно; исходные сокращения дорожной карты сохранены в раскрывающемся блоке. Два элемента с кодом 4.1.5 различены как 4.1.5а и 4.1.5б.

Список учеников

Одна строка — один ученик. Сохранение списка сохраняет результаты совпавших ФИО.

Как обновлятьДобавьте КОМ, укажите задания и внесите баллы. Изменения сохраняются в этом браузере. Для переноса на другой компьютер скачайте и загрузите резервную копию.

Новое мероприятие

Укажите основной элемент для каждого задания. Для ввода баллов сначала внесите максимум по шкале учителя. Проверяемое умение можно уточнить под содержание работы.
Ввод результатов

Для отсутствующих выбирайте «Не участвовал». Пустые и спорные результаты не превращаются в нули.
